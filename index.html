Game Features

⚔️
RPG Battle System
Answer trivia questions correctly to deal damage to enemies in a turn-based battle system.
❤️
Health / Lives System
Both you and your enemy have 3 hearts. Wrong answers cost HP. Run out and it’s Game Over!
🎨
Fantasy Pixel Art
Hand-crafted 2D pixel art characters, backgrounds, and UI elements built inside Godot.
🔊
Audio Manager
Global audioplayer.gd handles background music and sound effects throughout the game.
🏆
Win / Game Over Screens
Dedicated scenes for Game Over and Victory with Retry and Return to Menu options.
🧩
Block Coding Addon
Includes the block_code visual scripting addon for accessible, block-style game logic.

🎮 This is a Godot Desktop Game

Quiz Quest runs as a native desktop application using the Godot Engine — it cannot run directly in the browser without an HTML5 export. Browse all scenes, scripts, and assets on GitHub.
