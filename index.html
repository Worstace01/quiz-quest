🎮 About the Project

Quiz Quest is a game logic template and interactive knowledge quiz built inside the Godot Game Engine. It demonstrates Godot’s scene system, UI interactions, audio management, and state machines using GDScript.

It also includes support for block_code visual scripting via the addons system, making the project accessible to visual/block-based learners as well.

quiz-quest/
  ├── Assets/       # Images, sounds, fonts
  ├── Scenes/       # Godot scene files (.tscn)
  ├── Scripts/      # GDScript logic files (.gd)
  ├── addons/       # Plugins (block_code)
  ├── audioplayer.gd  # Global audio manager
  └── project.godot   # Godot project config

Key Features

💬
Interactive Quiz UI
Clean Godot UI for displaying questions and handling answer selection with instant feedback.
🎞️
Game State Management
Manages multiple game states: start screen, question phase, scoring, and end screen.
🔊
Audio Manager
Dedicated audioplayer.gd handles background music and sound effects globally.
🧩
Block Coding Support
Uses the block_code addon for visual, block-style scripting alongside GDScript.

🎮 This is a Godot Desktop Game

This game was built with Godot Engine and runs as a desktop application — it cannot run directly in the browser without a Godot HTML5 export. Browse the full source code on GitHub.
